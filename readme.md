# File Organizer Script

A bite-sized Python script that automatically organizes files in a directory
into folders based on file extensions.
- The script organizes files **only in the directory where it is placed and executed**.

## Features
- Skips hidden files and directories
- Avoids overwriting existing files
- Creates folders only when needed
- Tracks moved, skipped, and errored files

Place `organizer.py` inside the folder you want to organize, then run it.

## How to Run

### Windows
```zsh
python organizer.py
```
### MacOS
```zsh
python3 organizer.py
```
